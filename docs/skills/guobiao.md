# 国标麻将「竞赛规则」入门

国标麻将（中国麻将竞赛规则）是国家体育总局于 1998 年颁布的标准竞技规则，是所有麻将赛事（包括世界麻将锦标赛）的官方规则。它整合了各地麻将的精华，是目前最完整、最复杂的麻将体系。

## 基本参数

| 项目 | 说明 |
|------|------|
| **人数** | 4 人 |
| **牌数** | 144 张（含春、夏、秋、冬、梅、兰、竹、菊 8 张花牌） |
| **番数门槛** | 必须达到 **8 番** 才能胡牌 |
| **花牌** | 摸到花牌立即补牌，花牌计 1 番/张 |
| **结算** | 按番数计算，番数越高赢得越多 |

---

## 核心特色

### 1. 8 番起胡

国标最大的门槛：**必须有 8 番以上的番型组合才能胡牌。** 这意味着不能"鸡胡"，必须有意识地做牌。

新手最常用的 8 番组合策略：

| 组合 | 番数 | 说明 |
|------|:--:|------|
| 花牌 x2 + 门前清 + 平和 + 断幺 | 2+2+2+2=8 | 最基础的组合 |
| 混一色 + 门前清 + 幺九刻 | 6+2+1=9 | 做混一色 |
| 碰碰胡 + 断幺 | 6+2=8 | 全碰不贪大 |
| 全带幺 + 门前清 | 4+2=6… | 还差 2 番需要花牌凑 |

### 2. 花牌系统

国标有 8 张花牌，每张计 1 番：
- **春、夏、秋、冬** — 对应座位（庄=春, 南=夏, 西=秋, 北=冬）
- **梅、兰、竹、菊** — 4 张通用花

摸到花牌 → 立即亮出放桌角 → 从牌尾补一张 → 花牌自动加番。

### 3. 不重复计番原则

国标有一个重要规则：**同一副牌型中，互含关系的番型只计最高番。**

比如"清一色"（24 番）已经包含了"无字"（1 番），就不再单独算无字的 1 番。

## 番型分级速查

### 88 番（最高级）

| 番型 | 说明 |
|------|------|
| 大四喜 | 东南西北各一组刻子 |
| 大三元 | 中发白各一组刻子 |
| 九莲宝灯 | 1112345678999 + 同花色任意一张 |
| 四杠 | 四组杠子 + 一对将 |
| 连七对 | 同花色连续 7 对 |
| 十三幺 | 十三种幺九牌 + 任一对 |

### 64 番

| 番型 | 说明 |
|------|------|
| 小四喜 | 东南西北中三组刻子，另一组作将 |
| 小三元 | 中发白两组刻子，另一组作将 |
| 字一色 | 全部由字牌组成 |
| 清幺九 | 全部由 1 和 9 组成 |

### 48 番

| 番型 | 说明 |
|------|------|
| 一色四同顺 | 同花色四组相同的顺子 |
| 一色四节高 | 同花色四组递增的刻子 |

### 24-32 番

| 番型 | 说明 | 番数 |
|------|------|:--:|
| 清一色 | 同花色 | 24 |
| 一色三同顺 | 同花色三组相同顺子 | 24 |
| 全大 | 全部由 789 组成 | 24 |
| 全中 | 全部由 456 组成 | 24 |
| 全小 | 全部由 123 组成 | 24 |
| 三杠 | 三组杠子 | 32 |
| 混幺九 | 全部由幺九牌组成 | 32 |

### 常用低番（凑 8 番用）

| 番型 | 说明 | 番数 |
|------|------|:--:|
| 门前清 | 不吃不碰不杠听牌 | 2 |
| 平和 | 全顺子 + 非字牌将 | 2 |
| 断幺 | 无 1、9 和字牌 | 2 |
| 一般高 | 两组相同的顺子 | 1 |
| 老少副 | 123 + 789 同花色 | 1 |
| 幺九刻 | 有 1/9/字牌的刻子 | 1 |

## 新手策略

### 凑 8 番三步法

1. **保底 2+2+2**：门前清(2) + 平和(2) + 断幺(2) = 6 番，再摸 2 张花牌 = 8 番
2. **混一色路线**：混一色(6) + 幺九刻(1) + 门前清(2) = 9 番
3. **碰碰胡路线**：碰碰胡(6) + 断幺(2) = 8 番

### 关键提醒

- **花牌是宝贝** — 每张花牌就是 1 番，凑门槛的神器
- **不要轻易吃碰** — 门前清值 2 番，冲 8 番很好用
- **记番是基本功** — 建议把上面的番型表存手机里，边打边查

## 赛事信息

国标麻将每年都有正式赛事：
- **世界麻将锦标赛**（WMC）
- **中国麻将公开赛**
- **各地麻协组织的积分赛**

有兴趣参加比赛的，可以搜索当地麻将协会了解详情。
