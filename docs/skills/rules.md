# 🗺️ 各地麻将规则大全

中国地大物博，麻将玩法也是百花齐放。这里整理了最常见的几种麻将规则。

---

## 🇨🇳 广东麻将（鸡平胡）

广东地区最流行的玩法，节奏快、易上手。

### 基本规则
- **牌数**：136 张（万、筒、条 + 字牌，无花牌）
- **人数**：4 人
- **胡牌条件**：4 组面子 + 1 对将牌

### 特色规则
- **鸡胡**：只要能胡就胡，不限制番数，最低 0 番也能胡
- **平胡**：全部由顺子组成，无刻子
- **自摸**：自己摸到胡牌，三家各付一倍
- **点炮**：别人打出的牌让你胡，点炮者付三倍（包三家）

### 番型速查

| 番型 | 说明 | 番数 |
|------|------|------|
| 平胡 | 全顺子 + 非字牌将 | 1 番 |
| 碰碰胡 | 全刻子 | 2 番 |
| 混一色 | 一种花色 + 字牌 | 3 番 |
| 清一色 | 全部同一种花色 | 4 番 |
| 七小对 | 7 个对子 | 4 番 |
| 十三幺 | 十三种幺九牌各一张 + 任意一张成对 | 13 番 |

## 🌶️ 四川麻将（血战到底）

川麻以「缺一门」「血战到底」著称，刺激性极高。

### 特色规则
- **缺一门**：胡牌时手牌必须缺少一种花色（万/筒/条缺一种）
- **血战到底**：有人胡牌后，剩下的人继续打到只剩最后一人
- **刮风下雨**：杠牌有特殊收益（明杠/暗杠/补杠各有说法）
- **不可吃牌**：只能碰和杠，不能吃

### 番型速查

| 番型 | 说明 | 番数 |
|------|------|------|
| 根 | 四归一（杠） | 1 番 |
| 大对子 | 碰碰胡 | 1 番 |
| 清一色 | 缺两门 | 2 番 |
| 七对 | 七个对子 | 2 番 |
| 龙七对 | 七对中含一个杠（四张相同） | 3 番 |
| 清大对 | 清一色 + 碰碰胡 | 3 番 |
| 十八罗汉 | 四个杠 + 一对将 | 极罕 |

## 🎌 日本麻将（立直麻将 / リーチ麻雀）

日麻以策略深度著称，近年来在国内也越来越流行。

### 特色规则
- **立直（リーチ）**：听牌后可宣言进入立直状态，增加番数
- **有番才能胡**：必须满足至少一种役（番型），不能「鸡胡」
- **振听（フリテン）**：自己打过的牌不能胡别人的
- **点数制**：按番数和符数计算点数，满贯/跳满/倍满/役满

### 常见役种

| 役名 | 说明 | 番数 |
|------|------|------|
| 立直 | 听牌宣言，门清状态 | 1 番 |
| 断幺九 | 无幺九牌和字牌 | 1 番 |
| 平和 | 全顺子 + 两面听 | 1 番 |
| 一杯口 | 两组相同的顺子 | 1 番 |
| 混一色 | 一种花色 + 字牌 | 2-3 番 |
| 清一色 | 全部同一花色 | 5-6 番 |
| 国士无双 | 十三种幺九牌 + 一对 | 役满 |

---

## 🏘️ 长沙麻将

湖南长沙地区的特色玩法，节奏极快。

### 特色规则
- **二五八做将**：将牌必须是 2、5、8（万/筒/条均可）
- **大开放**：可吃可碰
- **扎鸟（抓鸟）**：胡牌后翻开牌山一张，按点数计算奖金倍率
- **小胡/大胡**：区分普通胡牌和特殊牌型

---

## 🎲 东北麻将

### 特色规则
- **不能缺门**：花色的要求与川麻相反，三种花色都要有
- **必须有幺九**：必须有 1 或 9 或字牌
- **门前清优先**：鼓励不吃不碰听牌

---

## 💡 通用建议

::: warning 打牌前问清楚
去不同的地方打牌，第一件事一定是**问清楚当地规则**！同样的牌型在不同规则下可能是胡牌也可能是诈胡。特别是：
- 有没有「缺一门」要求？
- 胡牌有没有番数下限？
- 能不能吃牌？
- 自摸和点炮的结算方式？
:::

---

_各地规则如有差异，以当地约定为准。有补充欢迎反馈！_
