# 广东麻将「鸡平胡」完全指南

广东麻将是华南地区最流行的麻将玩法，也是大多数麻将 App 的默认规则。节奏快、门槛低、老少皆宜。

## 基本参数

| 项目 | 说明 |
|------|------|
| **人数** | 4 人 |
| **牌数** | 136 张（万、筒、条 + 东、南、西、北、中、发、白） |
| **打法** | 鸡平胡 — 吃、碰、杠全开放 |
| **特色** | 最低 0 番也能胡，门槛极低 |
| **结算** | 自摸三家付；点炮包三家 |

---

## 核心规则

### 1. 鸡胡与平胡

广麻最核心的概念：

- **鸡胡**：只要有 4 组面子 + 1 对将牌就能胡，没有番数限制。**0 番也能胡。**
- **平胡**：全部由顺子组成（没有碰/刻），且将牌不能是字牌。1 番起。

### 2. 吃碰杠全开放

广麻是所有操作全开放的玩法：
- ✅ **可以吃** — 上家打的牌能和手牌凑顺子，喊"吃"
- ✅ **可以碰** — 任何人打的牌能和手牌凑刻子，喊"碰"
- ✅ **可以杠** — 明杠、暗杠、补杠都行

::: tip 吃碰优先级
碰 > 吃。如果同时有人要碰和要吃的同一张牌，碰的人优先。
:::

### 3. 自摸与点炮

广麻结算方式很直接：

| 胡牌方式 | 谁付钱 |
|----------|--------|
| **自摸** | 三家各付 1 倍 |
| **点炮** | 点炮者一人包赔三家（付 3 倍） |

## 与四川麻将的 5 大区别

| 对比维度 | 广东麻将 | 四川麻将 |
|----------|----------|----------|
| 牌数 | 136 张（有字牌） | 108 张（无字牌） |
| 吃牌 | ✅ 能吃 | ❌ 不能吃 |
| 缺门要求 | 无要求 | 必须缺一门 |
| 胡牌门槛 | 0 番就能胡 | 缺一门 + 成牌 |
| 多人胡牌 | 只有一人胡 | 血战到底，多人胡 |
| 结算 | 自摸三家付 / 点炮包三家 | 按番数计算 |

## 新手策略

### 开局阶段
1. **先看手牌番型潜力** — 如果起手花色均匀，走平胡路线；如果某种花色很多，可以冲混一色/清一色
2. **字牌处理** — 不成对的字牌优先打掉，除非想做混一色/字牌番型
3. **幺九牌** — 1 和 9 的牌比较难凑顺子，不用的优先弃

### 中期博弈
1. **观察对手吃碰** — 对手频繁碰字牌 → 可能在做混一色
2. **注意花色偏好** — 对手一直不出某花色 → 可能在憋清一色
3. **安全牌意识** — 别人碰过的牌附近是安全区

### 听牌阶段
1. **多面听优先** — 等一张 vs 等三张，概率差三倍
2. **生张小心** — 好久没人打的牌，很可能别人也在等
3. **别贪大** — 已经听牌了就别想着改做更大的，错过胡牌更亏
