# 四川麻将「血战到底」规则速成

四川麻将是全国最火爆的地方麻将玩法之一，以"血流成河""血战到底"著称。节奏快、刺激性高，深受年轻人喜爱。

## 基本参数

| 项目 | 说明 |
|------|------|
| **人数** | 4 人 |
| **牌数** | 108 张（万、筒、条各 36 张，**无风箭字牌**） |
| **打法** | 缺一门 — 必须打缺一种花色才能胡牌 |
| **摸牌** | 庄家 14 张，闲家 13 张 |
| **特色** | **血战到底** — 一人胡牌后其余三家继续打，直到只剩一家未胡或流局 |

---

## 核心规则

### 1. 缺一门是门槛

川麻最核心的规则：**手牌必须打缺一种花色，才有资格听牌和胡牌。**

- 缺万 → 手中没有万子牌
- 缺筒 → 手中没有筒子牌
- 缺条 → 手中没有条子牌

每局开始前，系统会自动为你选择缺哪一门（根据起手牌花色数量最少的那门）。

### 2. 血战到底

这是川麻最大的特色：

1. 第一家胡牌后，游戏**不停止**
2. 胡牌者退出，剩下三人继续打
3. 第二家胡牌后，剩下两人继续
4. 直到只剩最后一人未胡，或牌墙摸完 → 本局结束

所以即便你胡了，也可能输给胡得更大的人！

### 3. 不可吃、可碰可杠

- ❌ **不能吃牌**（只有上家打的牌不能拿来凑顺子）
- ✅ 可以碰
- ✅ 可以杠（明杠、暗杠、补杠）

## 胡牌牌型与倍数

| 番型 | 说明 | 倍数 | 难度 |
|------|------|:--:|:--:|
| 平胡 | 最基本的胡牌，缺一门即可 | 1 倍 | ⭐ |
| 对对胡 | 全部由刻子（碰碰）组成 | 2 倍 | ⭐⭐ |
| 清一色 | 全部同一种花色 | 4 倍 | ⭐⭐⭐ |
| 七对 | 7 个对子 | 4 倍 | ⭐⭐⭐ |
| 金钩钓 | 碰碰胡 + 只剩一张将牌 | 4 倍 | ⭐⭐⭐ |
| 龙七对 | 七对中含一个杠（四张相同） | 8 倍 | ⭐⭐⭐⭐ |
| 清大对 | 清一色 + 对对胡 | 8 倍 | ⭐⭐⭐⭐ |
| 十八罗汉 | 四个杠 + 一对将 | 极罕 | ⭐⭐⭐⭐⭐ |

### 杠牌特殊计算

| 杠类型 | 说明 | 收益 |
|--------|------|------|
| 暗杠 | 自己摸到四张相同，暗杠 | 每家给 2 倍 |
| 明杠（直杠） | 别人打出，你手上有三张 | 点杠者给 2 倍 |
| 补杠（巴杠） | 碰后再摸到一张，补杠 | 每家给 1 倍 |

::: warning 杠牌有风险
- **抢杠胡**：补杠时别人可以抢胡这张牌，赔了夫人又折兵
- **点杠**：别人碰后再摸到第四张算明杠，被杠者要包杠钱，所以牌局后期慎碰
:::

## 新手避坑指南

### ✅ 要做的
1. **优先打缺花色牌** — 摸到哪门少就打哪门，快速缺一门才能听牌
2. **中期看番型** — 鸡胡只能赢 1 倍，尽量往对对胡或清一色方向做
3. **记对手缺什么** — 别人缺万子，万字牌就安全，可以放心打
4. **胡小不如做大** — 反正血战到底，小胡先走不一定赚

### ❌ 不要做的
1. **不要乱碰** — 每次碰都会曝露自己的牌型方向
2. **不要盲目杠** — 会被抢杠，尤其是补杠
3. **不要憋三家** — 手里抓着别人缺门的花色没啥用，早点打掉
4. **不要只做平胡** — 别人做清一色比你多 4 倍，鸡胡赢了也亏
