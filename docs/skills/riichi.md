# 日本麻将「立直麻将」完全入门

日本麻将（リーチ麻雀 / 立直麻将）是日本最主流的麻将玩法，也是二次元玩家最熟悉的规则（《雀魂》《天才麻将少女》等都是日麻）。日麻强调防守和策略深度，被誉为"最优雅的麻将"。

## 基本参数

| 项目 | 说明 |
|------|------|
| **人数** | 4 人（也有 3 人规则） |
| **牌数** | 136 张（万、筒、条 + 字牌，无花牌） |
| **番数门槛** | **必须至少有一种役（番型）才能胡牌** |
| **分数** | 起始 25000 点，按番数和符数计分 |
| **振听** | 自己打过的牌不能胡别人的 |

---

## 日麻三大特色

### 1. 有役才能胡

日麻最大的门槛：**必须至少满足一种「役」才能胡牌。** 最常见的入门役：

| 役名 | 说明 | 番数 | 条件 |
|------|------|:--:|------|
| **立直（リーチ）** | 门清听牌后宣言 | 1 | 不吃不碰，听牌时交出 1000 点棒 |
| **断幺九** | 无 1、9 和字牌 | 1 | 手牌全是 2~8 |
| **平和** | 全顺子 + 两面听 + 非字牌将 | 1 | 必须门清 |
| **一杯口** | 两组相同的顺子 | 1 | 必须门清 |
| **役牌** | 有场风/自风/三元牌的刻子 | 1 | 如东家碰东风 |
| **混一色** | 一种花色 + 字牌 | 2-3 | 门清 3 番，副露 2 番 |
| **清一色** | 全部同花色 | 5-6 | 门清 6 番，副露 5 番 |

::: tip 新手保底策略
立直（1番）+ 断幺九（1番）+ 平和（1番）可以叠加！门清状态下立直，经常能做出 3-4 番的牌。
:::

### 2. 振听（フリテン）规则

**振听是日麻最独特的规则，也是最容易被忽略的陷阱：**

- **舍牌振听**：自己打过的牌，不能胡别人打的同一张
- **立直后振听**：立直后别人打的牌你没胡，此后永远不能胡那张
- **临时振听**：别人打的牌你没胡（不管什么原因），本轮内其他人再打也不能胡

::: danger 振听陷阱
经常有新手不小心振听，等了半天才发现胡不了。**养成习惯：摸牌前先检查自己是否振听。**
:::

### 3. 点数制

日麻不用番数直接算钱，而是用「番」和「符」计算点数：

| 番数 | 名称 | 子家点数 | 亲家点数 |
|:--:|------|--------|--------|
| 1 番 | — | ~1000 点 | ~1500 点 |
| 2 番 | — | ~2000 点 | ~2900 点 |
| 3 番 | — | ~3900 点 | ~5800 点 |
| 4-5 番 | 満貫 | 8000 点 | 12000 点 |
| 6-7 番 | 跳満 | 12000 点 | 18000 点 |
| 8-10 番 | 倍満 | 16000 点 | 24000 点 |
| 11-12 番 | 三倍満 | 24000 点 | 36000 点 |
| 13 番+ | 役満 | 32000 点 | 48000 点 |

## 役満（最高番型）

日麻最高级别的番型，出现的概率极低，胡到一次能吹一年：

| 役満 | 说明 |
|------|------|
| **国士无双** | 十三种幺九牌 + 任一对（对应中国的十三幺） |
| **四暗刻** | 四组暗刻 + 一对将（全靠自己摸） |
| **大三元** | 中发白各一组刻子 |
| **字一色** | 全部由字牌组成 |
| **绿一色** | 全部由 2/3/4/6/8 条 + 发组成 |
| **九莲宝灯** | 1112345678999 + 同花色任一张 |
| **天和** | 庄家起手即胡牌 |
| **地和** | 闲家第一巡摸牌即胡牌 |

## 与中麻的核心区别

| 对比 | 日本麻将 | 中国麻将（广东） |
|------|----------|-----------------|
| 胡牌门槛 | 必须有役（番型） | 0 番也能鸡胡 |
| 振听 | ✅ 有，很严格 | ❌ 无 |
| 花牌 | ❌ 无 | 各地区不同 |
| 食替 | ❌ 不能碰了马上换牌 | ✅ 各地区不同 |
| 流局 | 有多种流局规则 | 摸完就算流局 |
| 分数 | 25000 点起，按番符计算 | 按番数/倍数计算 |

## 新手快速上手路径

1. **下载雀魂** → 玩"友人场"熟悉基本操作
2. **记住 5 个基础役**：立直、断幺九、平和、役牌、混一色
3. **理解振听** → 这是新手最大的坑
4. **学会防守** → 对手立直后，打安全牌（现物/筋牌）
5. **多看高手打** → 在 B 站/Youtube 搜"日麻教学"

日麻入门难但精通后极有深度，加油！🀄
